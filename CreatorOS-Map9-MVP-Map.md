# CreatorOS Master Blueprint
## Map 9 — MVP Map
**Status: 🔒 LOCKED**
**Builds on: all prior maps**

---

## 1. What Must Exist (V1)

- Creator Profile (Creator Brain basics: identity, niche, audience, voice, goals)
- Creator Companion (basic conversational interface)
- Creative Board (idea → published status tracking)
- Strategy Agent (basic)
- Script Agent
- Feedback Learning System (simplified Learning Agent → Memory write)
- Home Dashboard + Workspace + Script Studio + Analytics (core screens only)
- Basic RBAC: Owner + Editor only (Viewer/Client deferred)

## 2. What Can Wait

- Visual Director Agent, Production Agent (full automation) — start manual/semi-manual
- CEO Advisor Agent — Weekly CEO Report can be a simple summary before it's a full agent
- Marketplace, Team Plans, Enterprise tier
- Trust Center / Privacy Center as dedicated screens (policies exist, dedicated UI can wait)
- Memory Center UI (memory exists on the backend; creator-facing view can follow)

## 3. Core User Value (the one thing V1 must prove)

A creator can go from **idea → published content → the system remembers and gets better next time.** Everything else is in service of proving that loop works. If that loop isn't real and felt by the creator, no other feature matters yet.
