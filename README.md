# Nextro - AI Operating System for Creators

🚀 A modern platform for content creators to manage, analyze, and grow their audience.

## Features

✅ **Dashboard** - Real-time analytics and performance tracking
✅ **Content Management** - Organize scripts, ideas, and production pipeline
✅ **AI-Powered Insights** - Get personalized recommendations
✅ **Beautiful UI** - Modern, dark-themed interface

## Quick Start

1. Visit: https://detrojakartik656-sys.github.io/Nextro/
2. Click "Get Started" to create an account
3. Access your creator dashboard

## Pages

- `index.html` - Landing page
- `login.html` - Authentication page
- `dashboard.html` - Creator dashboard
