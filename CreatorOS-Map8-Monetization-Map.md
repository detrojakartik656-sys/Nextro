## 1. Possible Models

| Model | Description |
|---|---|
| **Creator Subscription** | Core CreatorOS access — Companion, Creative Board, base agents |
| **Pro AI Agents** | Premium/advanced agents (e.g., deeper Research, advanced Performance Analyst) as an add-on tier |
| **Team Plans** | Multiple seats, shared Creative Board, roles from Map 6 (Editor/Viewer/Client) |
| **Enterprise Creator Studios** | Multi-brand management, advanced RBAC, dedicated support |
| **Marketplace** | Templates, agent presets, or creative assets shared/sold between creators |

## 2. How This Maps to Roles (from Map 6)

- **Owner** — subscription holder
- **Admin/Editor seats** — part of Team Plan tier
- **Client role** — read-only, likely bundled free with Team/Enterprise for external stakeholders

## 3. Notes for MVP

Monetization model choice affects nothing in Maps 1–7 structurally — subscription tiers gate *access* to modules already defined, they don't change the architecture. This keeps monetization decisions reversible without a redesign.
